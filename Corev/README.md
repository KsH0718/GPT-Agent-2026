# Corev 실행

## 공개 소스 보관본

비공개 제출 ZIP, API 키, 실행 환경은 이 저장소에 포함하지 않습니다.

## 이 개발 PC에서 실행

아이콘이 있는 **Corev 바로가기 (`Corev.lnk`)**를 더블클릭하세요.
VS Code나 터미널을 직접 열 필요가 없습니다. `Corev.cmd`도 같은 실행 기능을 제공합니다.
바로가기는 현재 설치 위치를 가리키므로 상위 프로젝트를 이동했다면 `Corev.cmd`를 사용하세요.

1. 실행 관리자가 AI 서버를 시작합니다.
2. 준비가 끝나면 주소창 없는 Chrome 앱 창으로 기존 Flutter 화면이 열립니다.
3. 사용 후 앱 창을 닫고, 실행 관리자의 **Corev 종료 (서버 함께 종료)** 버튼을 누르세요.
   실행 관리자 오른쪽 위 X를 눌러도 서버가 종료됩니다.
   Chrome 앱 창만 닫으면 서버는 계속 실행됩니다.

## 구성과 요구 사항

- Windows, 기존 상위 폴더의 Python 가상환경, Google Chrome을 사용합니다.
- 첫 실행 또는 화면 재빌드에는 기존 Flutter SDK와 패키지 다운로드용 인터넷이 필요합니다.
- 웹 빌드가 준비된 이후에는 Flutter 개발 서버 없이 실행합니다.
- 독립 설치형 EXE가 아니라 기존 프로젝트를 사용하는 로컬 앱 런처입니다.
  `Corev` 폴더만 따로 옮기면 작동하지 않습니다.
- API 키와 대화·업로드·결과 저장 위치는 기존 Integrated_agent 설정을 사용합니다.
  API를 사용하는 기능에는 인터넷과 유효한 서비스 키가 필요합니다.
- 원본 코드와 설정을 변경하지 않습니다. 실제 앱 사용 시 기존 서버가 대화·파일 데이터를
  원래 위치에 저장하는 동작은 그대로 유지됩니다.

## 수정한 화면 반영

앱을 종료한 후 `화면_다시빌드.cmd`를 더블클릭하세요.
원본 `flutter_app`의 웹 관련 소스를 Corev/runtime에 복사해서 빌드합니다.
완료하면 앱을 실행합니다. 일반 실행은 마지막 빌드 화면을 사용합니다.

## 문제 해결

- 8000 포트 사용 중: 기존 VS Code 등에서 실행한 서버를 종료하세요.
  런처는 다른 프로세스를 임의로 종료하지 않습니다.
- 이미 Corev가 실행 중이면 실행 관리자를 먼저 종료한 뒤 다시 실행하세요.
- 서버 오류: `logs/server.log`를 확인하세요.
- 빌드 오류: `logs/build.log`를 확인하세요.
- 실행 관리자 준비 중에는 종료를 잠시 제한합니다. 준비 완료 또는 오류 안내를 기다려 주세요.

## 개발자 검증

Corev 폴더의 PowerShell에서:

```powershell
..\venv\Scripts\python.exe .\launcher.py --smoke
```

웹 파일과 서버 기능 목록 응답을 확인한 뒤 자체 실행한 서버를 종료합니다.
이 검증은 실제 AI 응답이나 브라우저 렌더링을 검증하지 않습니다.
