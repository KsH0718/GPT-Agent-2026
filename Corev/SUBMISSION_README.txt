Corev — 교수님 제출용 Windows 실행본

1. ZIP 파일 전체를 쓰기 가능한 일반 폴더에 압축 해제합니다.
   압축파일 안에서 바로 실행하지 마세요.
2. Corev.cmd를 더블클릭합니다. Python/Flutter/VS Code 설치는 필요 없습니다.
3. 첫 실행의 API 설정에서 본인의 키를 입력하고 저장합니다.
   빈칸으로 저장해도 UI와 기능 목록은 확인할 수 있지만 AI 답변은 사용할 수 없습니다.
4. Chrome이 있으면 Chrome 앱 창, 없으면 Microsoft Edge 앱 창으로 열립니다.
5. 종료 시 실행 관리자에서 'Corev 종료'를 누릅니다.
   브라우저 창만 닫으면 서버는 계속 실행됩니다.

환경: Windows 10/11 x64 대상으로 구성했습니다. macOS/Linux/Windows ARM은 지원 대상이 아닙니다.
실제 다른 PC에서의 동작은 별도 확인이 필요합니다.
방화벽을 열거나 관리자 권한을 주지 않아도 localhost에서만 서버를 실행합니다.
8000 또는 18765 포트가 이미 사용 중이면 해당 앱을 종료한 후 재시도하세요.

API 사용:
- OpenAI: 일반 대화 및 관련 AI 기능에 필요합니다.
- Jev, Naver: 해당 기능을 사용하는 경우 각 서비스 키가 필요합니다.
- API-settings.cmd로 설정을 변경한 뒤 Corev를 재시작합니다.
- API 요청 비용은 입력한 키의 계정에 청구됩니다.
- 개발자의 API 키와 대화 기록은 포함하지 않습니다.
- 본인 키는 %LOCALAPPDATA%\CorevSubmission\.env에 평문으로 저장됩니다.
  이 데이터 폴더를 다른 사람에게 공유하지 마세요.

음성 인식:
- Python 음성 처리 라이브러리와 FFmpeg가 포함됩니다.
- 최초 로컬 음성 인식에는 Hugging Face 모델 다운로드가 필요합니다.
  인터넷·추가 디스크 공간이 필요하며 CPU에서는 오래 걸릴 수 있습니다.
- GPU 및 메모리 환경에 따라 사용 가능 여부와 속도가 달라집니다.

확인해 볼 순서:
1. 화면이 뜨고 도구 목록이 표시되는지 확인합니다.
2. OpenAI 키 설정 후 간단한 인사 또는 현재 시간 질문을 보냅니다.
3. 필요 시 문서 업로드, 뉴스 조회 등 각 기능을 확인합니다.
실제 AI 답변은 서비스 키의 유효성·잔액·네트워크에 영향을 받습니다.
이 안내는 모든 기능을 다른 PC에서 검증했다는 의미가 아닙니다.

데이터/로그:
%LOCALAPPDATA%\CorevSubmission
프로그램 파일과 별도로 대화, 업로드, 생성 결과, 모델, 로그를 저장합니다.
재배포 시에는 원래 제출용 ZIP을 사용하세요.

소스:
launcher.py: 앱 실행/종료 관리
submission_settings.py: API 설정
Integrated_agent/: 서버 및 도구 소스
web/: 빌드된 Flutter 화면
python/: Python 및 의존 패키지, 각 패키지 배포 메타데이터/라이선스
ffmpeg/: 기존 FFmpeg 배포본과 라이선스
DEPENDENCIES.txt: 포함 패키지 버전
